# ABISMO

Terror en primera persona a bordo del K-417 «Zarya», submarino soviético clase Tifón. Mar de Barents, octubre de 1989.
Eres el mecánico jefe: nueve años a bordo, conoces cada válvula. Y hay un compartimento, el 7, que no figura en los planos.

Parte en superficie, baja 400 metros mirando desde la cúpula y sigue adentro. Mobile first, three.js, audio sintetizado con Web Audio. 6 a 10 minutos, con final.

Juega en https://jona-mhw.github.io/abismo/ (con audífonos).
